# FR-01: Игрок получает баланс по идентификатору

## Пользовательская ценность
Игрок видит, сколько кредитов ему доступно, и может планировать ставки.

## Критерии приёмки
- [ ] GET /api/slots/balance/{userId} возвращает 200 и JSON {"balance": число}
- [ ] Для нового userId автоматически создаётся игрок со стартовым балансом 1000
- [ ] Повторный запрос возвращает тот же баланс, а не создаёт нового игрока

## Примечания
Статус в коде: реализовано (SlotsController.GetBalance).
