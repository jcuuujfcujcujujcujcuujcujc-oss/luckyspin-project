# US-01: Как игрок, я хочу видеть свой баланс, чтобы понимать, сколько могу поставить

## Пользовательская ценность
Игрок планирует ставки и не делает их вслепую.

## Критерии приёмки
- [ ] Баланс отображается на странице сразу после загрузки
- [ ] Новый игрок видит 1000 кредитов
- [ ] После каждого вращения баланс обновляется без перезагрузки страницы

Связь: FR-01 · Приоритет: Must · Оценка: 2 SP · Итерация 1
