# US-04: Как игрок, я хочу видеть историю своих вращений, чтобы контролировать свою игру

## Пользовательская ценность
Игрок контролирует траты и результаты.

## Критерии приёмки
- [ ] Каждое вращение попадает в историю с датой, ставкой, комбинацией и выигрышем
- [ ] Выводятся последние 20 записей, новые сверху
- [ ] Для игрока без вращений возвращается пустой список, а не ошибка

Связь: FR-05 · Приоритет: Should · Оценка: 5 SP
