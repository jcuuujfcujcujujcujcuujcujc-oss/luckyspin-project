# FR-03: Система начисляет выигрыш по правилам игры

## Пользовательская ценность
Правила выплат прозрачны и одинаковы для всех игроков.

## Критерии приёмки
- [ ] Три одинаковых символа дают выигрыш ставка × 5, баланс увеличивается на эту сумму
- [ ] При несовпадающих символах winAmount = 0 и баланс не увеличивается
- [ ] Правила выплат описаны в README и совпадают с кодом

## Примечания
Статус в коде: реализовано в SlotsController; в Services/SlotEngine.cs лежат другие правила (x2/x10/x20/x50), они не используются. См. TECH-01.
