# US-02: Как игрок, я хочу сделать ставку и увидеть результат вращения, чтобы играть в слот

## Пользовательская ценность
Основной игровой сценарий продукта.

## Критерии приёмки
- [ ] После ставки игрок видит три символа и сообщение о выигрыше или проигрыше
- [ ] Сумма ставки списывается, выигрыш (если есть) начисляется
- [ ] Результат приходит одним ответом API за разумное время (см. NFR-02)
