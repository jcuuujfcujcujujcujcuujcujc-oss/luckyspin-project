# US-06: Как оператор, я хочу блокировать игрока, чтобы пресекать нарушения правил

## Пользовательская ценность
Оператор может остановить недобросовестную игру. Вторая часть эпика «Управление игроками».

## Критерии приёмки
- [ ] После блокировки POST /api/slots/spin для игрока возвращает 403
- [ ] Оператор может снять блокировку, и игрок снова может играть
- [ ] Попытка заблокировать несуществующего игрока возвращает 404
