# FR-02: Игрок совершает ставку (spin)

## Пользовательская ценность
Игрок играет в слот и получает результат вращения.

## Критерии приёмки
- [ ] POST /api/slots/spin принимает {"userId", "betAmount"} и возвращает комбинацию, newBalance, isWin, winAmount
- [ ] Ставка списывается с баланса до начисления выигрыша
- [ ] Комбинация состоит из трёх символов в формате "A|B|C"

## Примечания
Статус в коде: реализовано частично (нет валидации ставки, см. FR-04).
