# NFR-01: Хеши паролей и роли доступа (версия 2)

## Пользовательская ценность
Учётные данные игроков защищены, а операторские методы доступны только оператору. Нужно для US-05 и US-06.

## Критерии приёмки
- [ ] Пароли хранятся только в виде хеша (PasswordHash), открытый пароль нигде не сохраняется и не логируется
- [ ] Методы /api/admin/* доступны только роли Operator, остальным возвращается 403
- [ ] Есть тест доступа к /api/admin/* без роли оператора

## Примечания
Версия 2: в MVP регистрации и авторизации нет (см. docs/PROJECT_CHARTER.md). Приоритет: Should · Оценка: 8 SP · Итерация 3.
