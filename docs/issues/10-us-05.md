# US-05: Как оператор, я хочу видеть список игроков и их балансы, чтобы контролировать состояние системы

## Пользовательская ценность
Оператор видит картину целиком. Часть бывшего эпика «Управление игроками».

## Критерии приёмки
- [ ] GET /api/admin/users возвращает список игроков (Id, Username, Balance, IsBanned)
- [ ] Пароли и хеши паролей в ответе отсутствуют
- [ ] Запрос без роли Operator получает 403
