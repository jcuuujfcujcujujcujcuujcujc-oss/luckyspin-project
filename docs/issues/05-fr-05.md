# FR-05: Игрок просматривает историю своих игр

## Пользовательская ценность
Игрок может проверить свои прошлые ставки и выигрыши.

## Критерии приёмки
- [ ] Каждый spin сохраняет запись GameLog (userId, ставка, выигрыш, комбинация, время)
- [ ] GET /api/slots/history/{userId} возвращает последние 20 записей, новые первыми
- [ ] История одного игрока не содержит записей другого

## Примечания
Статус в коде: не реализовано (модель GameLog есть, запись не ведётся).
