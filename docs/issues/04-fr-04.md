# FR-04: Система отклоняет некорректные ставки

## Пользовательская ценность
Игрок получает понятную ошибку, а баланс остаётся целым и не может быть накручен.

## Критерии приёмки
- [ ] betAmount <= 0 отклоняется с кодом 400 и понятным сообщением, баланс не меняется
- [ ] betAmount больше баланса отклоняется с кодом 400, баланс не меняется
- [ ] Несуществующий userId в spin возвращает 404

## Примечания
Статус в коде: НЕ реализовано для betAmount <= 0. Сейчас отрицательная ставка увеличивает баланс (уязвимость).
