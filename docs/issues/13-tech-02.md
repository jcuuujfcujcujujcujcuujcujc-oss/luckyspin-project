# TECH-02: Добавить проект автоматических тестов (xUnit)

## Пользовательская ценность
Регрессии ловятся автоматически; цель SMART-цели: не менее 5 тестов.

## Критерии приёмки
- [ ] Создан проект LuckySpinAPI.Tests, dotnet test проходит
- [ ] Не менее 5 тестов: баланс нового игрока, выигрыш, проигрыш, ставка <= 0, ставка > баланса
- [ ] Тесты не зависят от случайности (генератор подменяется)

## Примечания
Приоритет: Must · Оценка: 5 SP
