# Definition of Done

История или задача считается выполненной, если одновременно соблюдены все условия:

1. Код слит в основную ветку `main` через Pull Request, конфликтов нет; в описании Pull Request указано `Closes #N` для связанной Issue.
2. Код прошёл review минимум одним участником, **не являющимся автором**; замечания закрыты.
3. Проект собирается, `dotnet test` проходит, для нового поведения добавлены тесты (включая негативный случай).
4. Все критерии приёмки из Issue отмечены выполненными и проверены.
5. Документация обновлена: README и docs/ соответствуют коду, в репозиторий не попали секреты и файлы сборки (`bin/`, `obj/`, `.vs/`).

## Отличие от критериев приёмки

Критерии приёмки уникальны для каждой истории и отвечают на вопрос «что должна делать эта функция». Definition of Done общий для всех историй и отвечает на вопрос «что значит довести работу до конца».
